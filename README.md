# Luculent

Luculent 是面向 Minecraft Java 的光影包。提供日月天空、体积云与云影、植被风摆、彩色局部光、局部多弹 GI、水体反射与折射、水下散射，以及雨丝、涟漪和地表积水。

方块采用漫反射或粗糙 Glossy 着色：金属和平滑表面保留宽高光、沿纹理方向的各向异性和附近光源照明。方块及积水不绘制可辨认的场景镜像；水面保留独立反射和折射。

## 安装

在 [Releases](https://github.com/aCannedFish/Shader/releases/latest) 下载两个独立文件：

| 文件 | 用途 | 安装位置 |
| --- | --- | --- |
| `Luculent-0.3.1.zip` | 光影包 | 当前实例的 `shaderpacks/` |
| `Luculent-Materials-0.3.1.zip` | 可选 LabPBR 演示材质包 | 当前实例的 `resourcepacks/` |

在 OptiFine 光影菜单选择 Luculent，并启用法线贴图和镜面贴图。需要演示材质时，在资源包菜单启用 Luculent Materials。材质包只补充选定方块的法线和材质数据，保留游戏提供的原版颜色纹理；主要展示金属、平滑方块、染色块和矿物发光，不包含复杂的新纹理。

Shader 从资源包读取 LabPBR 1.3 数据，也可以搭配其他符合该标准的资源包。普通方块的粗糙度、金属参数及矿物发光遮罩不内置在 Shader 中。未提供材质数据时保留普通表面着色。半透明、镂空、楼梯和半砖继续使用游戏提交的几何与 alpha。

从旧版升级时，先备份原有设置。原有光影选项可复制为新光影文件同名的 `.txt`，例如 `Luculent-0.3.1.zip.txt`。旧的 `SimpleShader.txt` 也可按此方式迁移。0.2.x 使用的配套光照 Mod 应移除。

## 配置

0.3.1 提供 Low、Mid、High、Ultra 四档，默认使用 Mid。选择预设会同时设置高成本功能的开关及其预算，之后仍可逐项调整。雨水与积水保留独立开关。

| 预设 | 水体折射 | GI | 彩色光体积 | 视差 | 阴影分辨率 |
| --- | --- | --- | --- | --- | --- |
| Low | 关闭 | 关闭 | 关闭 | 关闭 | 1024 |
| Mid | 开启 | 单次表面反弹 | 32×16×32 格 | 基础，32 格内 | 1024 |
| High | 开启 | 多次反弹 | 48×24×48 格 | 较高，48 格内 | 2048 |
| Ultra | 开启 | 多次反弹，提高传播精度 | 64×32×64 格 | 高，64 格内 | 3072 |

Low 保留水波、水面倒影、基础阴影和材质高光，以约 60 FPS 为性能目标。High、Ultra 增加阴影、云倒影与体积采样，以约 30 FPS 为目标。实际帧率取决于场景、分辨率和显卡功耗。升级会保留已有个人选项，需要在光影菜单选择相应预设才能应用整组设置。

开发版在「后处理」中提供抗锯齿开关，可选关闭、FXAA 快速和 FXAA 质量。Low、Mid 使用快速档，High、Ultra 使用质量档。质量档搜索边缘端点，在边缘附近重建像素覆盖；均匀区域保留原色。处理位于色调映射与显示编码之后、输出抖动之前，游戏界面在后续正常绘制。这项后处理平滑几何与着色边缘，水体追踪中的错误命中或缺失场景仍需由光学路径处理。

水体选项可调整透明度、吸收、折射强度、水下光柱和反射质量。「水波强度」默认 1.5，可在 0.5 至 2.0 之间调整。波浪控制水面位移、折射和高光；倒影使用单独限制幅度的法线，只随水面轻微抖动。

水上看水下的浅化由同一次 Snell 折射求解产生。本开发分支沿折射光线查询水底，以相机和日月两个视角的原生深度寻找表面。相机视野外的材质取自游戏绘制时使用的贴图。近处还记录实际提交的面、四角 UV 和光照，供两个视角都看不到交点时查询。水面倒影会继续检索较远的原生面，以恢复草叶孔和山壁棱线背后的地形。镂空面按资源包的透明度决定覆盖。水下向水上看使用折射、全反射和波浪法线；这一路径排除第一人称手持物。玩家模型继续参与阴影等场景计算，正常手部显示保留。

当前开发版将倒影查询与水底求交分开：SSR 先建立深度交叉区间，再细化实际交点；原生面和带位置的局部环境记录补充缺失来源，最后回退到天空。局部记录只保留实际观察过的场景；转身、遮挡和大幅移动后可能缺少有效资料。水体滤波强度可单独调整或关闭，主要处理远处的细小噪点，保留近处细节；大块缺失场景仍受数据覆盖限制。流动水使用实际斜面或竖直面的朝向，结合薄水层折射、反射与轻微中性吸收。

## 环境

开发分支已检查两套 Minecraft 1.21.11 组合：OptiFine HD U J9 pre2 + Forge 61.0.8，以及 Iris 1.10.8 + Sodium 0.8.14 + Fabric Loader 0.20.1。使用 Java 21、Windows 11、RTX 4060 Laptop。Iris 已核对 Low、High 的水体画面和 High 的下界、末地切换；更多场景与长期运行仍需验证。正式 0.3.1 附件早于这次 Iris 适配。

Shader 使用 OpenGL 4.5 的计算、几何着色器与 image 原子操作。其他游戏版本和其他显卡尚未完成兼容验收。

0.3.1 的四档预设均核对了实际加载选项、GI 程序和阴影尺寸。RTX 4060 Laptop、1920×1080、视距 12、100% 内部尺寸下，每个性能场景预热后测量约 45 秒；当时另有用户游戏实例运行。Low、Mid、High、Ultra 的水岸平均值依次为 50.6、39.0、33.2、29.0 FPS，水下玻璃场景依次为 118.4、59.6、52.0、44.6 FPS，测试上限为 120 FPS。以上为并行负载下的结果，Low 水岸的约 60 FPS 目标仍未达到。

## 限制

- 水面反射结合屏幕空间与阴影信息，离屏表面和遮挡背面仍使用近似。树叶、复杂遮挡、掠射角和移动时仍可能出现暗片、碎片或不连续。
- 岸线折射的固定机位与连续移动检查已改善。原生透明三角形扩大了离屏覆盖，多层透明物仍受记录容量、追踪距离和游戏提交几何的限制。
- 独立演示包使用平坦法线和高度；Shader 的法线、视差支持不代表所有第三方材质包均已逐项验收。
- 雨雪、降水开关和四档预设已做原生检查；长时间运行及更多复杂场景仍需继续验证。

0.3.1 的改动见 [CHANGELOG.md](CHANGELOG.md)。上述限制保留在本次发布中。

## 源码

仓库的 `shaders/` 已是可直接加载的运行源码。将其连同许可文件放进光影目录，或压缩成根层包含 `shaders/` 的 ZIP 即可使用，无需额外装配工具。

根目录入口作为主世界与默认入口，`world-1/`、`world1/` 分别选择下界和末地。入口只定义维度与通道；`program/` 组织实际绘制步骤；`lib/` 按坐标、光照、大气、表面、水体和天气共享算法；选项集中在 `settings.glsl`。`lib/dimensions/` 分别保存三个维度的环境色、环境光和背景实现，编译时只选择当前维度。

水体由四个连续通道处理：`composite8` 求解水下出射，`composite9` 生成倒影辐射，`composite10` 求解水上透射，`composite11` 合成 Fresnel、介质和天气。独立组织这几条路径可减少驱动链接时的优化负担，并避开部分驱动的单程序指令限制。Iris 与 OptiFine 的渲染阶段及原生顶点偏移差异集中在 `lib/core/`，表面与光学算法复用同一套实现。

倒影查询位于 `lib/reflections/water_radiance_query.glsl`，只由反射通道引用。环境补充保留真实观察点和来源离散程度，再用当前深度验证接收面。场景源还保留原生粒子的平面类型，让折射沿正确的几何面求交，避免用稀疏邻域深度推断出错误平面。

屏幕反射与折射共用已有的分层深度遍历，反射独立设置访问预算和水面裁剪。交点取色限制在已通过几何验证的像素内；完整空区、越出屏幕与预算耗尽分别处理，避免把未知区域直接当作确认的天空。

局部环境补充中的发光表面还会按原生三角形检查支撑，保留实际形状、流体高度、UV 与透明裁剪。屏幕边缘过渡和离屏回退共用这一检查，减少稀疏观察把高亮颜色延伸到物体轮廓之外的情况。空间索引只筛选候选面，哈希单元不代表实体方块；没有完整几何资料时保留原有补充，仍受离屏覆盖限制。

流水和水柱按原生界面合成完整的透射、散射与反射颜色。有限水层按水方块横截面近似光程，竖直流向不在每个方块边界截断；水下出射使用独立的手部绘制前场景，天空颜色与几何有效标记分别保留。复杂瀑布的完整厚度、多层透明物和离屏覆盖仍有近似限制。

GPU 记录每帧初始化后再接收原生几何。Iris 在 `begin` compute 中初始化，OptiFine 在阴影 compute 中初始化，两者复用同一份程序；这样初始化与后续消费使用一致的帧 uniform，保持缓存和历史数据的有效性检查。

水体查询成对使用第一人称手部绘制前的世界颜色与深度，地形标记也从同一阶段保留。正常手部显示使用独立的主画面；玩家和装备的真实模型继续参与世界阴影与倒影，避免把摄像机专用的手持层重复映入水中。

仓库仅维护 Shader 源码、基本说明、许可和仓库配置。演示材质包作为独立 Release 附件提供；本地开发文档、调试工具、捕获和实验记录不纳入版本跟踪。
