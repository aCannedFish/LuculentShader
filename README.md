# Luculent

Luculent 是面向 Minecraft Java 的光影包。提供日月天空、体积云与云影、植被风摆、彩色局部光、局部多弹 GI、环境光遮蔽、水体反射与折射、水下散射，以及雨丝、涟漪和地表积水。

方块采用漫反射或粗糙 Glossy 着色：金属和平滑表面保留宽高光、沿纹理方向的各向异性和附近光源照明。雨后积水采用薄水膜镜面反射，并按 Fresnel 保留下层材质；水面保留独立反射和折射。

## 安装

在 [Releases](https://github.com/aCannedFish/LuculentShader/releases/latest) 下载两个独立文件：

| 文件 | 用途 | 安装位置 |
| --- | --- | --- |
| `Luculent-0.4.0.zip` | 光影包 | 当前实例的 `shaderpacks/` |
| `Luculent-Materials-0.4.0.zip` | 可选 LabPBR 演示材质包 | 当前实例的 `resourcepacks/` |

在 Iris 或 OptiFine 的光影菜单中选择 Luculent。OptiFine 需要启用法线贴图和镜面贴图。使用启动器的版本隔离功能时，应安装到对应版本的游戏目录。材质包在资源包菜单中独立启用，主要补充金属、平滑方块、染色块和矿物的材质参数，沿用游戏提供的原版颜色纹理。

Shader 读取 LabPBR 1.3 的粗糙度、金属、法线、视差和自发光数据，也可以搭配其他符合该标准的资源包。缺少材质数据时保留普通表面着色。半透明、镂空、楼梯和半砖使用游戏提交的几何与 alpha。

升级前备份个人设置。旧光影选项可复制为新文件同名的 `.txt`，例如 `Luculent-0.4.0.zip.txt`；已有选项会覆盖新的默认值。0.2.x 使用的旧配套光照 Mod 应移除。

## 配置

光影菜单按光照、环境、水体、材质和后处理分组，每项设置只有一处入口。采样步数、阴影范围及光照体积预算集中在「高级参数」。选择预设会调整高成本功能及其预算，之后仍可逐项修改。

| 预设 | 水体折射 | GI | 彩色光体积 | 视差 | 阴影分辨率 |
| --- | --- | --- | --- | --- | --- |
| Low | 关闭 | 关闭 | 关闭 | 关闭 | 1024 |
| Mid | 开启 | 单次表面反弹 | 32×16×32 格 | 基础，32 格内 | 1024 |
| High | 开启 | 多次反弹 | 48×24×48 格 | 较高，48 格内 | 2048 |
| Ultra | 开启 | 多次反弹，提高传播精度 | 64×32×64 格 | 高，64 格内 | 3072 |

Low 保留水波、倒影、基础阴影和材质高光，以约 60 FPS 为目标；High、Ultra 以约 30 FPS 为目标。预设保留个人的 TAA、FXAA 和调色选择，雨水与积水也有独立开关。

屏幕空间环境光遮蔽（SSAO）默认开启，在接触处和凹角削弱间接光，保留直射照明、高光与自发光。Low、Mid 使用八点近景采样，High、Ultra 使用十二点并延长覆盖距离。第一人称手部与水面不作为遮挡深度，真实玩家模型和原生镂空几何仍参与。

## 水体

静水与流水使用参考 BSL 独立适配的屏幕空间反射，保留细化、厚度检查、Fresnel 和边界过渡。反射方向额外检查前后关系，拒绝把近处屋顶、树叶错误投到更远的水面。屏幕边缘最多使用 2% 的有限深度延拓，只有已有几何标记的完整不透明接收面参与。

反射波纹和表面高光参考 BSL 的分层双向波形、远波与距离衰减，以轻微扰动保留倒影形状。水面调色保留亮度。静水、流水及积水的倒影共用空气散射：补齐物体至水面的空气段，再由主视图处理水面至玩家的空气段，使岸上体积光延续到倒影。

水底变浅由同一次 Snell 折射求解产生。相机、日月视图和原生面记录共同验证接收面，按真实 UV、光照和 alpha 读取材质。水下出射处理折射、全反射窗口和波浪法线，并使用手部绘制前的世界颜色与深度。玩家模型继续参与阴影和反射，正常手部显示保留。

流水依据实际斜面或竖直面的朝向计算薄层折射、反射和中性吸收。「倒影运动模糊」只处理倒影，静止时保留原色；Low、Mid 关闭，High、Ultra 开启。全屏运动模糊开启时跳过倒影专用模糊。

## 后处理

0.4.0 的默认后处理采用发布前 Fabric + Iris 实例的有效设置：

| 选项 | 默认值 |
| --- | --- |
| 抗锯齿 | TAA 关闭，FXAA 质量档 |
| 自动曝光 | 开启，曝光倍率 1.2 |
| 色调映射 | ACES |
| 调色 | 电影风格，强度 0.5，白平衡 0 |
| 饱和度、对比度 | 1.0、1.05 |
| Bloom | 开启，强度 0.4 |
| 镜头光晕 | 开启，强度 0.3 |
| 色差 | 开启，强度 1.5 |
| 暗角 | 0.1 |
| 景深、全屏运动模糊 | 关闭 |

TAA 在未经曝光的 HDR 颜色上累积，结合相机重投影、深度拒绝和邻域裁切；支持独立历史权重与锐化。关闭后使用所选 FXAA，也可以全部关闭抗锯齿。运动模糊、景深和 Bloom 位于显示变换前，FXAA 和输出抖动位于末端。

自动曝光使用中心加权对数测光，按曲线标定中灰，并在曝光档数上补偿 75%，保留明暗环境差别。曝光历史独立于 TAA，按时间平滑并限制单次推进；夜间和雨天补偿上限默认 1.25、1.5。真实闪电发生时保持曝光并暂停 TAA 历史累积，减少压暗和残影。

## 天气

提供可选雨丝、雨滴涟漪、薄体积雨雾与地表积水。积水按薄水膜 Fresnel 混合清晰倒影与下层材质，保留局部高光；普通方块继续使用漫反射或粗糙 Glossy。

原生闪电保留游戏电弧的折线和分叉，照亮附近云体与雨雾，并通过 HDR Bloom 扩散。效果响应真实事件，不生成额外闪电。区块平滑过渡可以在高级参数中独立关闭。

## 环境

已检查 Minecraft 1.21.11 的两套组合：Iris 1.10.8、Sodium 0.8.14、Fabric Loader 0.20.1；以及 OptiFine HD U J9 pre2、Forge 61.0.8。使用 Java 21、Windows 11 和 RTX 4060 Laptop。Shader 需要 OpenGL 4.5 的计算、几何着色器和 image 原子操作。

发布前在同一渲染算法上进行的 1920×1080、视距 8、100% 内部尺寸短时采样中，Low 水岸约 76.9 FPS、水下约 100.7 FPS；High 水岸同客户端交替对照约 27.2 FPS。另有用户游戏实例运行，结果只供对应场景参考，不能代表所有硬件或场景。

## 限制

- SSR 无法恢复屏幕外或完全被遮挡的景物。复杂植物、遮挡轮廓与掠射角仍可能出现缺口和边缘误差，有限延拓无法补全场景。
- 原生透明层受记录容量、追踪距离和游戏提交几何的限制。第三方材质包及复杂模型尚未逐一验收。
- TAA 没有独立的实体和骨骼速度，高速实体、植物动画及复杂透明层可能残影；景深无法恢复前景遮挡的背景。
- 首次编译新的水体配置仍可能较慢。发布前的新折射变体重载约 58 秒；驱动缓存命中后的重复变体及曝光、调色调整约 1 秒，缓存不保证长期保留。
- 其他游戏版本、显卡和平台，以及长时间运行，尚未完成全面验证。

## 源码

仓库的 `shaders/` 可直接加载，无需装配工具。根入口作为主世界与默认入口，`world-1/`、`world1/` 选择下界和末地；`program/` 组织绘制步骤，`lib/` 按功能共享算法，选项集中在 `settings.glsl`。

水体由 `composite8` 至 `composite11` 分别处理水下出射、倒影、水上透射及最终合成。反射只导入所需模块，透射与出射共用几何和材质查询；光照体积寻址、辐照度及兼容接口集中维护。其他维度不使用的主世界分支在预处理时排除。

仓库仅保存 Shader 源码、基本文档、许可和仓库配置。演示材质包单独发布；本地开发文档、调试工具、捕获和未采用实验不纳入版本跟踪。
